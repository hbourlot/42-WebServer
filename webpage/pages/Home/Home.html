About The Project

Webserver is a project from the 42 curriculum whose goal is to implement an HTTP server from scratch in C++, following the HTTP/1.1 standard. This server is capable of handling multiple clients simultaneously, processing GET, POST, and DELETE requests, serving static files, executing CGI, and managing configurations through a file similar to Nginx.

We built it as a team of three to deeply understand client-server communication, network architecture fundamentals (sockets, poll, and more), and core web protocol concepts.
