Welcome to our Webserver

Webserv is a project from the 42 curriculum whose goal is to implement an HTTP server from scratch in C++, following the HTTP/1.1 standard. This server must be capable of handling multiple clients simultaneously, processing GET, POST, and DELETE requests, serving static files, executing CGI, and managing configurations through a file similar to Nginx.

In this project, we worked as a group of three to gain a deep understanding of how communication between client and server works, the fundamentals of network architecture (sockets, poll, etc.), and the core concepts of web protocols.
